# 🎓 School Management System

A **modern Flutter-based School Management System** designed to digitize and streamline academic and administrative workflows. The application provides **secure, role-based access** for Admins, Incharges, Teachers, and Parents, ensuring transparency, efficiency, and better communication across the school ecosystem.

---

## 🚀 Overview

The **School Management System** is a cross-platform mobile application built with **Flutter** and powered by **Firebase**. It centralizes essential school operations—attendance, assignments, exams, and progress reports—into a single, intuitive platform that is easy to use and scalable for future needs.

---

## 👥 User Roles & Capabilities

### 🛡️ Admin

* Manage teachers, parents, and students
* Monitor overall school performance
* View consolidated reports and analytics

### 🧑‍🏫 Incharge

* Supervise classes and teachers
* Track attendance and academic progress
* Handle complaints and reports

### 👩‍🏫 Teacher

* Mark and manage student attendance
* Create, upload, and evaluate assignments
* Process leave requests
* Review student academic performance

### 👨‍👩‍👧 Parent

* View student profile and academic details
* Check attendance via calendar view
* Access day-wise and weekly timetables
* Track assignments and submissions
* View exam results and progress reports
* Submit leave requests and complaints

---

## ✨ Core Features

* 🔐 **PIN-based authentication** with role selection
* 📱 **Dedicated dashboards** for each user role
* 📅 **Timetable management** with horizontal day-wise scrolling
* 📆 **Attendance calendar** with monthly overview
* 📝 **Assignment creation, tracking & submission**
* 📈 **Progress reports** with grades, ranks, and overall scores
* 🏆 **Exam analysis** with subject-wise marks
* 🎨 **Custom UI themes**, app bars, and navigation drawers
* ♻️ **Reusable & clean Flutter widgets** following best practices
