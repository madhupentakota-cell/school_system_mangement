# 📘 School Management System

A **Flutter-based School Management System** application designed to digitize and simplify school operations by providing **role-based access** for Admin, Incharge, Teacher, and Parent users. The app improves communication, transparency, and efficiency in academic and administrative workflows.

---

## 🚀 Project Overview

The School Management System is a mobile application built using **Flutter** for cross-platform UI and **Firebase** as the backend. It centralizes school-related activities such as attendance, assignments, exam results, and progress reports into a single, user-friendly platform.

---

## 👥 User Roles & Features

### 🛡️ Admin

* Manage teachers, parents, and students
* View overall school performance
* Access reports and analytics

### 🧑‍🏫 Incharge

* Monitor classes and teachers
* Track attendance and academic progress
* Handle complaints and reports

### 👩‍🏫 Teacher

* Mark student attendance
* Upload and manage assignments
* Handle leave requests
* View student performance

### 👨‍👩‍👧 Parent

* View student profile and details
* Check attendance (calendar view)
* View timetable (day-wise & weekly)
* Track assignments and submissions
* View exam results and progress reports
* Submit leave requests and complaints

---

## 📊 Key Features Implemented

* 🔐 PIN-based authentication & role selection
* 📱 Separate dashboards for each user role
* 📅 Timetable (horizontal day-wise scrolling)
* 📆 Attendance calendar with monthly view
* 📝 Assignment creation and submission
* 📈 Progress reports with grades, rank, and overall score
* 🏆 Exam result analysis (subject-wise marks)
* 🎨 Custom themes, app bars, and drawers
* ♻️ Reusable and clean Flutter widgets

* **Flutter & Dart** – Cross-platform mobile development
* **Firebase** – Authentication, database, notifications

## 🎯 Project Objective

The main goal of this project is to:

* Reduce manual paperwork
* Improve communication between school and parents
* Provide a centralized digital platform for school management
* Enable real-time access to academic information
